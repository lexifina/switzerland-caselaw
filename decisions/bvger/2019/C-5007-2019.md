Demnach verfügt das Bundesverwaltungsgericht: 
1. 
Das Beschwerdeverfahren wird als gegenstandslos geworden abgeschrie-
ben. 
2. 
Die Verfahrenskosten von Fr. 2'500.– werden der Beschwerdeführerin auf-
erlegt. Dieser Betrag wird dem geleisteten Kostenvorschuss entnommen. 
Der Restbetrag von Fr. 2'500.– wird der Beschwerdeführerin zurückerstat-
tet. 
3. 
Es wird keine Parteientschädigung zugesprochen. 
4. 
Dieser Entscheid geht an die Beschwerdeführerin, die Vorinstanz und das 
BAG.

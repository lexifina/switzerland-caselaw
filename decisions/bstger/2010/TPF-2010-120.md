# Bundesstrafgericht TPF 2010 120

## Regeste

Weigerung des BJ, eine schriftliche Zusicherung auszustellen betreffend Nichtfestnahme im Hinblick auf eine Auslieferung; Prüfung des BJ ist beschränkt auf offensichtliche Unzulässigkeit des Ersuchens um Kooperation; Gesuch, das auf die Erhebung von Beweismitteln abzielt.
